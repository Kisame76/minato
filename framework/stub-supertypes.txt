# Classes of framework.jar that may still stand on a stub supertype (ADR-0039 b3.4): such a class compiles against a
# stub and cannot load, so tools/framework-check.sh fails on any other. Each entry names the step that removes it,
# or, since b3.5a, says "stays: <reason>", why the class never loads on Minato's path, or, since step c2c3, "gap:
# <what>", an app's path that fails today without a step yet; the check fails on an entry with none of them, and on
# any entry that no longer stands on a stub.
# <class> -> <supertype>  # <the step that removes it> | stays: <why it never loads> | gap: <what fails>
