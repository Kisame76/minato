# The guest's /system/etc/public.libraries.txt (ADR-0040 decision 3): the public libraries of Android 15's list that
# Minato's guest system has, in Android's order and format. libnativeloader preloads each of them when the VM starts
# and aborts the start if one fails, so a library comes in only with the step that brings it. The graphics front
# libraries came with ADR-0041 a). Their preload costs app_process no measurable start time, as libandroid_runtime
# links 4 of them anyway (libvulkan opens MoltenVK in about 2 ms on the Mac), and dalvikvm about 6 ms. libjnigraphics
# came with ADR-0041 a5, marked nopreload, which libnativeloader's format has: a preload would load hwui's set at
# every VM start, dalvikvm's too, which Android's zygote does once; an app that needs it loads it at its own start.
